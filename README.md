# Free VIN History Aggregator API

Сервис асинхронной OSINT-агрегации данных об автомобилях из открытых источников.

## Концепция (Executive Summary)
Вместо обхода платных API через уязвимости, спроектирован асинхронный сервис, собирающий ключевые данные (пробег, аукционные фото, историю объявлений) из открытых источников абсолютно бесплатно.

## Архитектура
- **FastAPI + Asyncio**: Параллельные запросы к источникам дают время ответа < 1.5 сек.
- **httpx**: Асинхронный HTTP-клиент.
- **BS4 + Regex**: Извлечение структуры из неструктурированного контента.
